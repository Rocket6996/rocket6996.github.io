# astro-razbot-site

Лендинг Telegram-бота [@astro_razbot](https://t.me/astro_razbot) — разбор
натальной карты, прогноз на день, совместимость.

Статический сайт, раздаётся через GitHub Pages. Страницы генерируются
скриптом `tools_build_site.py` из закрытого репозитория бота — правки
вносятся там и пересобираются, а не редактируются здесь вручную.
